# Security policy

## Supported versions

RailScout is pre-release software. Security fixes are applied to the latest
commit on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability-reporting flow for
`piwanczak/railscout`. Do not open a public issue for a vulnerability or include
credentials, API keys, cookies, personal data, or carrier response payloads in
a report.

Reports should include the affected route or component, realistic impact, and
the smallest safe reproduction. Reports are handled on a best-effort basis;
there is no response-time commitment or bounty program.
